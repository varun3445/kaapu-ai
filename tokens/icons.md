# Icon Reference

Source: `lucide-react`. These are **not** importable as Figma tokens/variables — icons map to Figma components, not values. This list exists so a designer can build matching Figma components manually or via Code Connect.

## Sizing & Stroke Rules

| State | Size | Stroke |
|---|---|---|
| Active (selected tab) | 19px | 2.5 |
| Inactive nav | 19px | 1.8 |
| Action buttons | 16–18px | 2.0 |
| In-card icons | 12–14px | 2.0 |

## Sets

**Navigation** — Home, BookOpen, Sparkles, Users

**Actions** — Bell, X, Plus, Trash2, Search, Download, ExternalLink, Filter, MoreHorizontal

**Status** — AlertTriangle, CheckCircle, ShieldCheck, ShieldAlert, Loader, Clock

**Health** — Heart, Pill, Activity, TrendingUp, TrendingDown

**People** — User, UserCheck, UserX, Phone, MapPin

**Misc** — Settings, FileText, ChevronDown, ChevronUp
