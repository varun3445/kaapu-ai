# Glassmorphism

## Rules

| ✅ Do | ❌ Don't |
|---|---|
| Stack glass on the `#eeeae6` surface | Use glass on solid white (no effect) |
| Use `.glass-card` for content panels | Nest `.glass-elevated` inside `.glass-card` |
| Use `.glass-elevated` for modals only | Use light text on `.glass` (low contrast) |
| Keep text `#1f2937` for contrast | Add extra box-shadow on top of `.glass-card` |
